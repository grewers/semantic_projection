Repo for the Bachelor Thesis "Implementing Semantic Projection in the LSAfun R package. A new R function for text data analysis".

From Edna Grewers at Humboldt-Universität zu Berlin.

This repo contains the function `semantic_projection()` to do semantic projection in R. These functions are meant to be added to the R package (LSAfun)[https://cran.r-project.org/web/packages/LSAfun/index.html].

You can find the function, including check functions in the folder 'R'. It also includes the documentation (man) file in the folder 'man', and tests for both `semantic_projection()` and the check functions in the folder 'tests'.
